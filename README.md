# 🚀 TechZone - Comunidade de Tecnologia

Uma plataforma web moderna desenvolvida com foco em comunidade, interação e compartilhamento de conteúdo tecnológico, com destaque para setups gamers e troca de conhecimento entre usuários.

---

# 📌 Sobre o Projeto

O **TechZone** é um portal criado como trabalho avaliativo da disciplina de **Desenvolvimento Web**, com o objetivo de aplicar na prática conceitos de:

* ✅ Estruturação com **HTML5**
* ✅ Estilização avançada com **CSS3**
* ✅ Responsividade
* ✅ Experiência do Usuário (**UX/UI**)

A proposta é simular uma comunidade online de tecnologia, onde usuários podem explorar conteúdos, interagir e compartilhar seus próprios setups.

---

# 🎯 Funcionalidades

## 🏠 Página Inicial (Home)

* Banner principal com imagem de fundo
* Apresentação da comunidade
* Seções informativas sobre tecnologia
* Ranking de membros

## 📝 Cadastro

* Formulário para entrada de usuários na plataforma

## 💬 Fórum

* Espaço para interação entre os membros
* Compartilhamento de ideias e discussões

## 🖼️ Galeria de Setups

* Exibição dos setups enviados pela comunidade

## 🎮 Envio de Setup Gamer

Formulário personalizado contendo:

* Nome/Nickname
* E-mail
* Nome do Setup
* Upload de imagem
* Descrição do setup
* Preview da imagem antes do envio
* Reset inteligente do formulário (incluindo a imagem)

## 📞 Contato

* Informações para comunicação com a comunidade

# 🚀 Como Executar o Projeto

1. Clone o repositório:

```bash
git clone https://github.com/seu-usuario/techzone.git
```

2. Acesse a pasta:

```bash
cd techzone
```

3. Abra o arquivo:

```bash
index.html
```

ou utilize a extensão **Live Server** do VS Code.
